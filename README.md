# ChainPulse — Multi-Chain Portfolio & Wallet Security

[![npm](https://img.shields.io/npm/v/approval-guardian.svg)](https://www.npmjs.com/package/approval-guardian)
[![Version](https://img.shields.io/badge/api-8.0.0-blue)](https://chainpulse-api-vf5g.onrender.com/health)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

Real-time multi-chain portfolio tracker with built-in wallet security auditing.

## Quick Start

```bash
npx approval-guardian
```

## API

- Health: https://chainpulse-api-vf5g.onrender.com/health
- Dashboard: https://chainpulse-api-vf5g.onrender.com/dashboard

## Features

- **7 EVM chains** — Ethereum, BSC, Polygon, Arbitrum, Optimism, Base, Avalanche
- **Bitcoin, Solana, TRON** — native balance scanning
- **Wallet hygiene score** — 0–100 based on approvals, dust, activity
- **HTML export** — professional security reports

## Disclaimer

Educational / authorized security auditing only.
